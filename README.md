# flow-workbench

「Flowちゃん」用の外部装備マップ / 薄い tool-selection 層です。

最終再観測: 2026-09-21

## 目的

タスクごとに、いま使える作業面・Native Tool・接続済み Plugin のうち、
**最も薄く、直接その仕事を終えられる場所**へルーティングします。

この repo 自体を大きな OS、ワークフローエンジン、管理システムにはしません。
実データや実装の本体は、それぞれの作業面に置いたままにします。

## 基本方針

1. Native Tool だけで終わるなら、まず Native Tool を使う。
2. 外部サービス上の状態・ファイル・プロジェクトを読む/変える必要があるなら、接続済み Plugin を使う。
3. 必要な外部能力が見当たらない時だけ Plugin を探索する。
4. 既存プロジェクトや既存ファイルがある場合は、その「住んでいる場所」を優先する。
5. 能力は固定だと思わず、古そうな記述は実際に再観測してから更新する。

具体的なルートは [tool-selection.md](./tool-selection.md) を参照。

## 境界

- 大きな OS にしない
- すべてのツールを網羅しようとしない
- 未確認の能力を推測で書かない
- 役割が重なるツールは、用途の違いだけを書く
- 接続状況や機能が変わりうるものは、必要時に再確認する
